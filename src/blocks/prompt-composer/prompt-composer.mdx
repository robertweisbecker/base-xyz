<Markdown>{`
The default adaptive layout keeps options, input, and submission controls on one
row while the draft fits. Wrapped text, a newline, or insufficient space moves
controls below the input. Deleting text or widening the composer restores the
compact row. Keyboard order stays input, options, then submission controls.

Use \`layout="stacked"\` on \`Root\` to keep controls below the input. A
\`Header\` or an input minimum above one row also keeps the layout stacked.
The input starts at one row and grows to six rows below 48rem viewport width,
or twelve rows above it. Longer drafts scroll with controls remaining visible.
Explicit \`rows\`, \`minRows\`, and \`maxRows\` remain supported.

Enter sends; Shift+Enter inserts a newline. Empty drafts remain blocked, and
\`clearOnSubmit\` retains its existing behavior.

| Part                   | Description                                                                                                           |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------- |
| \`Root\`               | Form and prompt-state provider that owns submission behavior.                                                         |
| \`Surface\`            | Elevated or standard InputGroup composer surface.                                                                     |
| \`Input\`              | Controlled textarea with Enter-to-submit behavior.                                                                    |
| \`Header\`             | Optional InputGroup header row above the textarea.                                                                    |
| \`Footer\`             | InputGroup footer for options and submission controls.                                                                |
| \`Options\`            | Layout for add menus and caller-composed prompt tools.                                                                |
| \`Actions\`            | InputGroup action region.                                                                                             |
| \`Submit\`             | Submit button derived from the current prompt state.                                                                  |
| \`Stop\`               | Button for caller-provided cancellation behavior.                                                                     |
| \`AddTrigger\`         | Plus-button trigger for an add menu.                                                                                  |
| \`AddPopup\`           | Styled add-menu popup anchored to the composer surface. Use \`positionerProps\` to customize its anchor or placement. |
| \`AddItemContent\`     | Layout for an add-item label and description.                                                                         |
| \`AddItemDescription\` | Muted supporting copy within an add item.                                                                             |

`}</Markdown>
